# ARES // Planet Colonizer

Interface web futurista de gerenciamento de uma colônia humana em Marte, ambientada em 2096.

## Funcionalidades demonstrativas
- Painel de recursos vitais: água, alimentos, energia e oxigênio.
- Indicadores operacionais e ambientais.
- Gráfico de crescimento populacional e distribuição de colonos.
- Monitoramento de infraestrutura.
- Central de alertas e registro de telemetria.
- Relógio em tempo real, notificações e ações simuladas.
- Layout responsivo para desktop, tablet e celular.

## Tecnologias
- HTML5
- CSS3 (Grid, Flexbox, gradientes e media queries)
- JavaScript puro (DOM, eventos e atualização dinâmica)

## Executar
Abra `index.html` em um navegador. Não há dependências ou instalação.

## Publicar no GitHub Pages
1. Crie um repositório público chamado `planet-colonizer`.
2. Envie `index.html`, `style.css`, `script.js` e `README.md` para a raiz.
3. Acesse Settings → Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Escolha `main` e `/ (root)` e salve.
6. Aguarde o endereço aparecer na página do GitHub Pages.

## Observação
Os dados, alertas e controles são simulações para fins acadêmicos. O projeto não está conectado a sensores ou infraestrutura real.
